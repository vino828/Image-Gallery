# 🖼️ Image Gallery Website

## 📌 Project Description
The Image Gallery is a responsive web application developed using HTML, CSS, and JavaScript. It displays images in an attractive grid layout with category-based filtering options. Users can explore images, filter them by category, and view images in a larger lightbox preview.

## 🎯 Features
- Responsive image grid layout
- Category-based image filtering
- Lightbox image preview
- Smooth hover animations using CSS
- Attractive and user-friendly interface
- Mobile-friendly design
- Easy image navigation

## 🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling, animations, and responsive layout
- JavaScript – Image filtering and lightbox functionality

## 🚀 How to Run the Project
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open the index.html file in your browser.
4. Click the category buttons to filter images.
5. Click any image to view it in a larger preview.
